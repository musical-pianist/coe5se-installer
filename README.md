# CoE5SE Installer

This is a repo that aids users in installing the Script Extender and Jazzy mods. It was made separate in an attempt to more easily change updates and put the Script Extender on platforms that might think poorly about commands being added that install from GitHub.

How to run it: [CoE5SE's Install](https://github.com/musical-pianist/coe5se#install)
