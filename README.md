# CoE5SE Installer

`install.ps1` (Windows) and `install.sh` (Mac) install [CoE5SE](https://github.com/musical-pianist/coe5se) from its latest release and every [Jazzy mod](https://github.com/musical-pianist/coe5se-mods-suite) from the mods' repository, into your mods folder, replacing older copies. Then they copy one file into the game folder: `glu32.dll` next to `CoE5.exe`, or `coe5se.dylib` next to `coe5_mac`. With `COE5SE_ONLY` set, they install CoE5SE alone. They change nothing else, and stop if the game is running.

The commands that run them are in CoE5SE's [Install](https://github.com/musical-pianist/coe5se#install).
